# @elyvel/validation

Laravel-style validation for elyvel — rule DSL, message bag, FormRequest

Part of [elyvel](https://github.com/ufhy/elyvel) — a Laravel-inspired, Elysia-first framework for Bun.

## Installation

```bash
bun add @elyvel/validation
```

## Requirements

Bun. This package uses Bun-native APIs and does not run on Node.

See the [elyvel documentation](https://github.com/ufhy/elyvel#readme).
