# @elyvel/create

Scaffold a new [elyvel](https://github.com/ufhy/elyvel) app.

## Usage

```bash
bun create @elyvel my-app
```

Both `bun create @elyvel` and `npm create @elyvel` resolve to this package.

Options: `--kit=vue|spa|none` picks the starter kit.

## Requirements

Bun. elyvel uses Bun-native APIs and does not run on Node.
