# @elyvel/telegram

Telegram Bot API client for elyvel — send messages (and a notifications channel)

Part of [elyvel](https://github.com/ufhy/elyvel) — a Laravel-inspired, Elysia-first framework for Bun.

## Installation

```bash
bun add @elyvel/telegram
```

## Requirements

Bun. This package uses Bun-native APIs and does not run on Node.
