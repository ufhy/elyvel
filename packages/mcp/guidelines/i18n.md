## Localization (@elyvel/i18n)

- Translate with `trans('messages.welcome', { name })` from `@elyvel/i18n`
  (`transChoice` for plurals); files live in
  `lang/<locale>/`. A package's own strings live under a namespace
  (`auth::errors.unauthenticated`) and can be overridden from
  `lang/vendor/<package>/`.
- The request locale is set per request; `currentLocale()` reads it and
  `runWithLocale(locale, fn)` scopes a different one (for a queued job or a
  mail rendered for another user).
- User-facing strings — validation messages, mails, notifications — should go
  through `trans`, not be hard-coded.
