# @elyvel/notifications

Laravel-style notifications for elyvel — multi-channel (mail/database/telegram/broadcast)

Part of [elyvel](https://github.com/ufhy/elyvel) — a Laravel-inspired, Elysia-first framework for Bun.

## Installation

```bash
bun add @elyvel/notifications
```

## Requirements

Bun. This package uses Bun-native APIs and does not run on Node.
