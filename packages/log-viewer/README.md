# @elyvel/log-viewer

A web UI for browsing storage/logs/*.log — install and gate it yourself, no environment magic

Part of [elyvel](https://github.com/ufhy/elyvel) — a Laravel-inspired, Elysia-first framework for Bun.

## Installation

```bash
bun add @elyvel/log-viewer
```

## Requirements

Bun. This package uses Bun-native APIs and does not run on Node.
