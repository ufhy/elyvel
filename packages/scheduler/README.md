# @elyvel/scheduler

Laravel-style task scheduling for elyvel — cron expressions, fluent frequencies, schedule:run

Part of [elyvel](https://github.com/ufhy/elyvel) — a Laravel-inspired, Elysia-first framework for Bun.

## Installation

```bash
bun add @elyvel/scheduler
```

## Requirements

Bun. This package uses Bun-native APIs and does not run on Node.
