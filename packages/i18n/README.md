# @elyvel/i18n

Localization for elyvel — translation lines, :placeholder replacement, and pluralization (mirrors Illuminate\Translation)

Part of [elyvel](https://github.com/ufhy/elyvel) — a Laravel-inspired, Elysia-first framework for Bun.

## Installation

```bash
bun add @elyvel/i18n
```

## Requirements

Bun. This package uses Bun-native APIs and does not run on Node.
